## Conclusion

**H1 (N-HRC) is closed by evidence.** Every N-HRC route requires authentication: the tenant route requires `get_current_user` + `require_tenant_access`; the state route requires `get_caan_user`; the reference/mapping routes require `get_current_user`. Unauthenticated and invalid-token calls are rejected; foreign-tenant access is blocked; regulator/super-admin state access is intact.

**Residual (documented, not fixed):** `/api/v1/nhrc/tenant/*` (and `/api/v1/nhrc/mapping-rules`, `/seis`, `/contributing-factors`) are **not** in `ENDPOINT_MODULE_MAP`, so they are not module-gated by the RBAC middleware; protection is route-level only. Same class as `/api/v1/dashboard*` and `/api/v1/spi/tenant/*` — **item 1A.4**. No middleware entry added in 1A.3.
