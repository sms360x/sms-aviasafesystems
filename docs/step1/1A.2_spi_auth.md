## Conclusion

**H1 is closed by evidence.** Every SPI route requires authentication: tenant routes require `get_current_user` + tenant scope; state routes require `get_caan_user`. Unauthenticated/invalid calls are rejected; a non-regulator tenant user is forbidden from state routes; foreign-tenant access is blocked; regulator/super-admin cross-tenant access is intact.

**Residual (documented, not fixed):** `/api/v1/spi/tenant/...` is **not** in `ENDPOINT_MODULE_MAP`, so it is not module-gated by the RBAC middleware; protection is route-level only. Mirrors the `/api/v1/dashboard*` gap (item 1A.4). No middleware entry added in 1A.2 (requires SME approval).
