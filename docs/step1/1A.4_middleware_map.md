## Verification sub-tasks

### (a) Public tenant-lookup (`routes/auth.py:430-462`) — FLAGGED (item 1A.10)
Returns more than the display name: `tenant_id` (the **slug**), `tenant_name`, `classification`, `operates_flights`, `applicable_departments`. Reachable with either an invite `code` or a `?tenant=<slug>` query (`:434-435`), guarded only by App Check (`:436`), not auth. Returning `tenant_id` (slug) contradicts SME rule **L6** ("never expose a slug to an end user"), and the `?tenant=` fallback needs no invite code. Recorded as **item 1A.10** (response trim + sandbox removal + server-side survey-window/active enforcement).

### (b) Archetype selector (`services/archetype_scope.py`) — SAFE
`resolve_data_tenant` honours `archetypeId` **only** when it starts with the reserved `demo-` prefix (`:19,31-32`); otherwise it falls back to the caller's own `tenant_id` (or `default`). It cannot resolve to a real tenant, so the caller-supplied selector is safe for any authenticated user. No action.
