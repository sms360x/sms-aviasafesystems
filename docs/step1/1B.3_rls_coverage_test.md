test asserts **configuration**, not enforcement.

## Enforcement assertion — skip reason

`test_rls_enforcement_not_assertable_on_app_path` calls `pytest.skip` with:

> RLS is not enforced on the app path: the backend connects as the table owner
> with `rls_forced=false` and the live policies read Supabase GoTrue claims that
> the Firebase app path never presents. Configuration-only coverage. See
> `docs/step1/rls_bypass_finding.md` and `docs/step1/1B.2_rls_exemptions.md`.

The enforcement check is skipped with a reason rather than silently passing, per
1B.3's requirement.

**Yes — a tenant-owned table without RLS is detectable by the suite.** Any

and the enforcement assertion is skipped with a reason.
