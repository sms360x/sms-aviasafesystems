## What the middleware does

`backend/app/middleware/rbac_middleware.py`: maps request paths to modules (`ENDPOINT_MODULE_MAP`), normalizes legacy roles via `app/core/rbac.py`, rejects a role lacking module permission (403), rejects a disabled tenant module flag (403), and blocks a tenant user from a path whose `tenant_id` differs from their session (403). Cross-tenant roles (`CAAN_SMD`, `SUPER_ADMIN`) bypass the module gate but not tenant isolation.

No new security code and no new test were written: this finding is already fixed and a regression test already exists. The plan's "verify + regression test" was satisfied by running the existing suite.
