## 3. Template applied per classification

**Template A — UUID tenant column (31 policies).** Outcome/mandatory (13) add
the regulator branch; operator-only (18) do not.

```sql
USING (
  current_setting('app.current_role', true) = 'SUPER_ADMIN'
  OR tenant_id = NULLIF(current_setting('app.current_tenant', true), '')::uuid
  -- outcome/mandatory only:
  OR (
    current_setting('app.current_role', true) = 'STATE_SMD'
    AND EXISTS (
      SELECT 1 FROM public.oversight_relationships o
      WHERE o.regulator_tenant_id =
              NULLIF(current_setting('app.current_tenant', true), '')::uuid
        AND o.operator_tenant_id = tenant_id
        AND o.effective_to IS NULL
    )
  )
)
WITH CHECK (
  current_setting('app.current_role', true) = 'SUPER_ADMIN'
  OR tenant_id = NULLIF(current_setting('app.current_tenant', true), '')::uuid
)
```

- Outcome/mandatory (regulator branch): `hazards`, `risk_register`,
  `barrier_register`, `sram_risk_register`, `bow_tie_analyses`,
  `bow_tie_threats`, `bow_tie_consequences`, `bow_tie_controls`,
  `safety_deficiencies`, `sms_maturity`, `regulatory_reports`,
  `flight_diversions`, `psoe_assessments`.
- Operator-only (no regulator branch): `action_items`, `cans`, `caps`,
  `closures`, `corrective_actions`, `hazard_triage`, `import_batches`,
  `import_links`, `import_mappings`, `import_rows`, `safety_communications`,
  `sag_meetings`, `srb_meetings`, `survey_responses`, `surveys`,
  `verifications`, `module_c_aggregates`, `state_risk_register`.

**Template B — text (slug) tenant column (1 policy).** `caan_reports`:

```sql

```

**Split (1 policy).** `reports`:

```sql
USING (
  <SUPER_ADMIN>
  OR <tenant match>
  OR (report_type = 'mandatory' AND <STATE_SMD oversight>)
)
-- WITH CHECK: tenant / SUPER_ADMIN only
```

**Role / state (9 policies).** `caan_reports`, `metric_definitions`,
`module_c_aggregates`, `regulatory_reports`, `state_risk_categories`,
`state_risk_register`, `taxonomy_mappings` cross-tenant policies, plus
`p_module_c_aggregates_national` and
`p_state_safety_performance_targets_caan`:

```sql
USING (current_setting('app.current_role', true) = ANY (ARRAY['STATE_SMD','SUPER_ADMIN']))
```

(`module_c_aggregates_national`: `tenant_id IS NULL AND role = 'STATE_SMD'`.)

All comparisons use the **canonical** role names and `NULLIF(...,'')` guards, so
an unset GUC fails closed (deny) instead of erroring.
