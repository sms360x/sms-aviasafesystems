## 2. The canonical list defined

`app/core/config.py` (module-level, so `from app.core.config import
DEPARTMENT_CODES` works):

```python
DEPARTMENT_CODES = [
    ("safety", "Safety"), ("flight_ops", "Flight Operations"),
    ("camo", "CAMO"), ("maintenance_145", "Part-145"), ("qa", "QA"),
    ("ground_ops", "Ground Operations"), ("airside_ops", "Airside Operations"),
    ("arff", "ARFF (Rescue & Firefighting)"),
    ("smd", "Safety Management Division"),
    ("fssd", "Flight Safety Standards Division"),
    ("assd", "Aerodrome Safety Standards Division"),
]
DEPARTMENT_LABELS = {code: label for code, label in DEPARTMENT_CODES}
DEPARTMENT_CODES_SET = {code for code, _ in DEPARTMENT_CODES}
department_code(value)  # code-or-label -> canonical code
```

Also: `normalize_department` now delegates to `department_code` (returns a
**code**), and `OperationalScope` validates at import that every declared code is
canonical.
