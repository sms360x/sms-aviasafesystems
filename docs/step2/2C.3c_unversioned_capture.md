## 3. Drift test

File: `backend/tests/test_rls_drift.py`.

Repo side: every `CREATE POLICY` across `supabase/migrations/`, with the **last
occurrence per `(table, policy_name)` winning** (a later migration supersedes an
earlier one). Dynamic `EXECUTE format(... %I ...)` statements are skipped (their
policies are superseded by later explicit statements). Live side: `pg_policy`
joined to `pg_class`/`pg_namespace`, with `pg_get_expr(polqual, polrelid)` and
`pg_get_expr(polwithcheck, polrelid)`.

**Primary — normalized text.** Live `pg_get_expr` vs the raw migration clause;
both canonicalised (cast suffixes, `public.` qualification, identifier quoting
and whitespace removed; parentheses and string-literal case **kept** so a
precedence or role-literal change cannot normalize away).

**Fallback — deparse round-trip.** When the primary reports a difference, the
repo statement is replayed on its table inside a **rolled-back transaction**,
re-read with `pg_get_expr`, and compared byte-for-byte with the live clause.
Both sides pass through the same Postgres deparser, so this separates real drift
from a normalization artifact. Live state is never persisted (always rolled
back). No flag or authentication required.

Assertions: every live policy exists in the repo; every repo policy exists in
live; per `(table, policy_name)` the `USING`/`WITH CHECK` (and `cmd`, `roles`,
`permissive`) match; platform-internal exemptions are named explicitly
(`PLATFORM_EXEMPT`, empty today). Skip reasons are explicit (cannot connect;
fallback required but cannot run) — never silent.

### Result

- Primary comparison: differences reported on all 57 policies — **all
  normalization artifacts** (the deparser adds `::text`/`::uuid` casts,
  `public.`/table qualification and parentheses).
- Fallback (deparse round-trip): **57/57 match, 0 real drift.**
- `pytest backend/tests/test_rls_drift.py -v` → **5 passed.**
